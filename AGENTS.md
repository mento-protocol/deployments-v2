# Mento Deployments V2 Instructions

For any protocol-level question that crosses beyond this deployments repo, first
read the private `mento-master-context` router when the checkout is available:

```text
../mento-master-context/.agents/mento-context/README.md
```

This applies before broad repo searches for questions about contracts,
monitoring semantics, live on-chain state, docs, the whitepaper, business model,
or legal/risk framing. Load only the relevant master-context card(s), then return
to this repo for deployment details. For addresses and ABIs, this repo and the
generated `@mento-protocol/contracts` package remain the source of truth. For
current on-chain state, resolve the address here and verify with live RPC at an
explicit block. When answering, mention which master-context card you used or
state that the checkout was unavailable.

Ownership covers design and cleanup, not authority: approval rules, scope sign-off, review and no-merge rules still apply. Keep related fixes in separate commits and list them in the PR body.
